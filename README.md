# هُنا الروابي

موقع عربي متجاوب بهوية المنيو البرتقالية والكريمية، تصفية وبحث في الأصناف، سلة طلب عبر واتساب، صور المنيو الأصلية، وأزرار الاتصال والموقع والإنستجرام.

## تشغيل

من مجلد المشروع: `npm start` (Python 3 مطلوب)، ثم افتح المنفذ 3000 محلياً. لا يحتاج الموقع تثبيت حزم أو خادم قاعدة بيانات. `npm run check` يتحقق من صياغة JavaScript.

البيانات والأسعار في `app.js`، الهوية في `style.css`، والروابط والساعات في `index.html`. الصور في `assets/` هي النسخ الأصلية المرفقة، ويستخدم التصميم مواضع CSS لعرض تفاصيلها بدون تعديل الملفات. صور الأقسام توضيحية من المنيو وليست صورة منفصلة لكل صنف. الأسعار تشمل تفسير +1 للدبل و+0.60 للخبز الفرنسي و+0.20 للبطاطس الوسط وفق المنيو.

## النشر

ارفع المشروع إلى فرع `main`. من Settings → Pages اختر GitHub Actions كمصدر النشر. يتولى `.github/workflows/pages.yml` نشر الملفات العامة فقط. يمكن أيضاً رفع `index.html` و`style.css` و`app.js` ومجلد `assets` إلى أي استضافة ملفات ثابتة. النشر يحتاج صلاحية على حساب الاستضافة.
